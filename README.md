# liftnull

Lift color null values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/liftnull/

## Install / run

```bash
git clone https://github.com/theworker02/liftnull.git
cd liftnull
node src/cli.js
node --test
```
